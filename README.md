# منصّة أ. ‹اسم المعلّم› — القدرات الكمّي والتحصيلي

منصّة تعليمية **مدفوعة** لمعلّم رياضيات واحد وطلّابه المشتركين: يرفع فيها
ملفّاته وروابطه واختباراته، ويوزّعها على مجموعاتٍ يقسّمها هو، ويقبل اشتراكات
الطلاب بنفسه.

> 🔴 **مشروعٌ جديد يبدأ من الصفر.** لا شفرة ولا قاعدة بيانات ولا حساب استضافة
> ولا نطاق ولا مستخدمين مشتركين مع أي مشروعٍ آخر للمالك. المنقول من المشروع
> السابق هو **الخبرة وحدها** — أنماطٌ وأخطاءٌ وقعت فعلاً، مجموعةٌ في
> `docs/المرجع/٢-خبرات-هندسية-منقولة.md`.

## القسمان

المنصّة مقسومةٌ مسارين منفصلين، لكلٍّ **اشتراكه المستقلّ**:

| المسار | المحتوى |
|---|---|
| **القدرات — الكمّي** | شروحات القسم الكمّي. **الكمّي فقط** — لا لفظي |
| **التحصيلي — الرياضيات** | مادّة الرياضيات لاختبار التحصيلي |

والفصل بينهما **مفروضٌ في قاعدة البيانات لا في الواجهة**: طالبٌ مشترك في
التحصيلي وحده لا يقرأ صفّاً واحداً من محتوى القدرات ولو عبث بالطلب يدوياً.
وهذا مُختبَرٌ لا مُدّعىً — انظر `db/test/01_track_separation.test.sql`.

## التشغيل

### فحوص قاعدة البيانات (لا تحتاج Supabase)

```bash
./db/test/run.sh              # قاعدة مؤقّتة تُنشأ وتُهدَم
./db/test/negative-control.sh # إثبات أنّ الفحوص ليست عمياء
```

يلزم Postgres مثبَّتاً محلّياً (أو `DATABASE_URL` لقاعدةٍ قائمة).

### الواجهة

```bash
cd app && npm install
cp .env.example .env          # ثم املأ القيم
npm run dev
```

بلا `.env` تعرض الواجهة شاشة إعدادٍ تشرح الخطوات — لا أخطاء شبكةٍ غامضة.

### كل الفحوص

```bash
node scripts/check-contrast.mjs --self-test     # التباين يُقاس لا يُقدَّر
cd app && npx tsc --noEmit && npx vitest run && npx vite build
node scripts/check-conventions.mjs --self-test
./db/test/run.sh && ./db/test/negative-control.sh
```

## ربط مشروع Supabase

1. أنشئ مشروعاً **جديداً ومستقلّاً** لهذه المنصّة وحدها.
2. طبّق `supabase/migrations/*.sql` بالترتيب.
3. سجّل حساب المعلّم من الواجهة، ثم أضفه مرّةً واحدة بـSQL:
   ```sql
   insert into private.teachers (user_id) values ('<معرّف المستخدم>');
   ```
   لا واجهة تفعل هذا ولا دالّة — **بعمد**: لا باب ترقيةٍ ذاتية في المشروع.
4. املأ `app/.env`.

## قواعد لا تُنقَض

هذه ليست تفضيلات. كلّ واحدةٍ منها خطأٌ وقع فعلاً وكلّف وقتاً.

1. **الحارس في الأسفل.** لا شرط صلاحيةٍ يُكتب في الواجهة بديلاً عن القاعدة.
2. **كل دالّة جديدة في `public`:** اسحب `EXECUTE` من `PUBLIC`، وامنحه لمن
   يحتاجه، وحدّث `db/security/expected-grants.txt`. وإلا أرسب التدقيق البناء.
3. **سمة العرض على `html` لا على `body`.**
4. **كل تاريخٍ يمرّ بـ`lib/format.ts`.** لا `toLocaleDateString` في مكانٍ آخر.
5. **لا `raise exception` بعد نجاح كتابة** — يُلغي المعاملة كلّها. أعد قيمة.
6. **لا نجاح كاذب.** ما لم يُكتب يُبلَّغ عنه بعددٍ صريح.
7. **فحصٌ جديد يحتاج إثباتاً أنّه يرسب** الخللَ الذي بُني لالتقاطه.
8. **حدِّث `docs/سجل-المشروع.md` مع كل قرار.** الذاكرة عبر الجلسات لا
   يُعتمد عليها.
